# Stork

Varios agentes de Claude Code trabajando a la vez, cada uno en su propio worktree de git.
App de escritorio para macOS. Acá sólo están las descargas; la documentación está en
**[sevenstork.com/apps/stork](https://sevenstork.com/apps/stork)**.

## Descargar

[**Última versión para Mac**](https://github.com/FedericoSebastian/stork-releases/releases/latest/download/Stork-universal.dmg) · macOS 11 o más nuevo · Apple Silicon e Intel.

Abrís el `.dmg` y arrastrás Stork a Aplicaciones. Está firmada y notarizada por Apple, así que abre sin avisos.
Las versiones anteriores quedan para siempre en la [lista de releases](https://github.com/FedericoSebastian/stork-releases/releases).
